# platform-datalake

OpenSearch catalog CDK. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/platform-datalake-archive`.

Hosted-zone choice uses `CDK_DEV_ACCOUNT`. Generated `cdk.context.json` was **removed**.

No contract deployments recorded in this repo.

## What was built (EN)

platform-datalake provisions OpenSearch infrastructure for catalog data. `PlatformDatalakeStack` creates an `OpenSearchCatalogConstruct` against a Route 53 hosted zone.

## Qué se construyó (ES)

OpenSearch de catálogo en CDK. Contexto CDK de AWS eliminado.
